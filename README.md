# KLH-CSE-2026-27-2420030558-ComplaintManagement
# AI-Powered Banking Customer Complaint Management System using BERT

## Project Overview

This project develops an AI-powered banking customer complaint management system using BERT. The system is designed to automatically understand and classify customer complaints and help manage them through a web-based platform.

When a customer submits a complaint, the complaint text is processed and given to a fine-tuned BERT model. The model predicts the Product, Sub-product, Issue, and Sub-issue of the complaint. Based on these predictions, predefined business rules are used to determine the department, priority, response time, ticket ID, and employee assignment.

The system contains three main modules: Customer, Employee, and Administrator. Customers can submit and track complaints, employees can manage assigned complaints, and administrators can manage users, complaints, departments, and system analytics.

## Dataset

### CFPB Consumer Complaint Database

The project uses the **Consumer Financial Protection Bureau (CFPB) Consumer Complaint Database**.

Official Dataset Source:

https://www.consumerfinance.gov/data-research/consumer-complaints/

The main input to the BERT model is:

**X / Input:**
- Consumer Complaint Narrative

The model predicts:

**Y / Output:**
- Product
- Sub-product
- Issue
- Sub-issue

Other fields in the original dataset are not used as model inputs when they are not required for complaint classification.

Application-specific information such as Ticket ID, Department, Priority, Assigned Employee, Response Time, and Complaint Status is generated by the complaint management system.

## Business Rule Engine

The Business Rule Engine uses the predictions made by the BERT model to decide the appropriate department, priority, response time, and employee assignment.

For example:

Product = Credit Card  
Issue = Fraud  

↓

Department = Credit Card Fraud  
Priority = High  
Response Time = Based on predefined rules  
Ticket ID = Generated by the system  
Employee = Assigned from the relevant department

These application-generated fields are not taken from the CFPB dataset.
